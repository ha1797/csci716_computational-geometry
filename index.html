Project Overview

This project is an interactive, web-based application designed to visualize the Plane Sweep algorithm for detecting line segment intersections. The Plane Sweep algorithm is a fundamental technique in computational geometry that reduces a two-dimensional problem into a dynamic one-dimensional problem by sweeping a vertical line across the plane from left to right.

While the algorithm is efficient—running in O((n + I) log n) time, where n is the number of line segments and I is the number of intersections—its dynamic nature can be difficult to understand from static diagrams alone. This tool aims to bridge that gap by animating the algorithm step by step, allowing students to see exactly how the sweep line, event queue, and sweep-line status interact with each other.

The application will feature a side-by-side view: the left panel will display the geometric plane with the sweep line and line segments, while the right panel will show the current state of the data structures—the Event Queue (a priority queue of future events) and the Sweep-Line Status (an ordered list of segments currently intersecting the sweep line). Important operations such as insertion, deletion, adjacency checks, and swaps will be visually highlighted.
