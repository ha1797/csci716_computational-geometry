Problem Description

This project is an interactive, web-based application designed to visualize the Plane Sweep algorithm for detecting line segment intersections. The Plane Sweep algorithm is a fundamental technique in computational geometry that reduces a two-dimensional problem into a dynamic one-dimensional problem by sweeping a vertical line across the plane from left to right.

While the algorithm is efficient—running in O((n + I) log n) time, where n is the number of line segments and I is the number of intersections—its dynamic nature can be difficult to understand from static diagrams alone. This tool aims to bridge that gap by animating the algorithm step by step, allowing students to see exactly how the sweep line, event queue, and sweep-line status interact with each other.

The application will feature a side-by-side view: the left panel will display the geometric plane with the sweep line and line segments, while the right panel will show the current state of the data structures—the Event Queue (a priority queue of future events) and the Sweep-Line Status (an ordered list of segments currently intersecting the sweep line). Important operations such as insertion, deletion, adjacency checks, and swaps will be visually highlighted.

Algorithms & Pseudo-Code

The implementation uses the plane-sweep technique. A vertical sweep line moves across the plane (here from right to left), stopping only at events: segment endpoints and intersection points. At every stop, only segments that are adjacent along the sweep line are tested for intersection, so the work depends on n + I rather than on all n² pairs.

Input assumptions (checked before the sweep runs):

  • No vertical or horizontal segments.
  • No two segments are colinear.
  • No three segments pass through the same intersection point.

Data structures:

  • Event Queue Q – a binary heap ordered by x (largest first), then by y (largest first), then by type (start < intersection < end).
  • Sweep-Line Status T – a skip list of the segments crossing the sweep line, ordered bottom to top by their y-value at the current sweep position (ties broken by slope).
  • Output I – the list of intersection points found.
PlaneSweep(S):
    Q ← empty event queue
    T ← empty sweep-line status
    I ← empty list

    for each segment s in S:
        Q.insert(START(s)) at the right endpoint of s
        Q.insert(END(s))   at the left endpoint of s

    while Q is not empty:
        e ← Q.extractNext()
        x ← e.point.x                      // move the sweep line to x

        if e is START(s):
            T.insert(s)
            CheckIntersection(T.below(s), s, x)
            CheckIntersection(s, T.above(s), x)

        else if e is END(s):
            a ← T.above(s);  b ← T.below(s)
            T.delete(s)
            CheckIntersection(b, a, x)          // a and b are now adjacent

        else if e is INTERSECTION(s1, s2):
            if s1 and s2 are both still in T:  // ignores duplicate events
                I.append(e.point)
                swap s1 and s2 in T             // their order flips past the crossing
                (lower, upper) ← new order of s1, s2
                CheckIntersection(T.below(lower), lower, x)
                CheckIntersection(upper, T.above(upper), x)

    return I


CheckIntersection(a, b, x):
    if a or b is null:
        return
    p ← IntersectionPoint(a, b)
    if p exists and p.x ≤ x:                 // only crossings still ahead of the sweep
        Q.insert(INTERSECTION(a, b)) at p


IntersectionPoint(((x1,y1),(x2,y2)), ((x3,y3),(x4,y4))):
    d ← (x2-x1)(y4-y3) - (y2-y1)(x4-x3)
    if d = 0:
        return none                      // parallel
    t ← ((x3-x1)(y4-y3) - (y3-y1)(x4-x3)) / d
    u ← ((x3-x1)(y2-y1) - (y3-y1)(x2-x1)) / d
    if 0 ≤ t ≤ 1 and 0 ≤ u ≤ 1:
        return (x1 + t(x2-x1), y1 + t(y2-y1))
    return none

Running time: there are 2n endpoint events and I intersection events. Each event performs a constant number of queue and status operations, each costing O(log n) (expected, for the skip list), for a total of O((n + I) log n) time and O(n + I) space.
